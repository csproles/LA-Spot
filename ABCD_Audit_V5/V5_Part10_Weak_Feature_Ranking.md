# Part 10 — Weak Feature Ranking

Ranking basis: code correctness (Parts 6–9), feature distributions on the **locked test set**
(`V5_Feature_Failure_Analysis.csv`, n=615, independently reconstructed and verified to reproduce the
published TP/TN/FP/FN exactly), sensitivity to segmentation errors, and calculation stability. Every
locked-test statistic below closely replicates the separate development-cohort ablation study
(`Evaluation_FeatureEngineering/feature_analysis_table.csv`, n=2090) — this consistency across two
disjoint cohorts is itself evidence these are real, reproducible patterns rather than one-cohort noise.AC
No feature is deleted or changed here.

Rank scale: **appears stable** / **needs manual verification** / **potentially weak** / **implementation concern**.
Problem categories for anything below "appears stable": **A** segmentation-related, **B**
feature-calculation problem, **C** weak discrimination between classes, **D** insufficient evidence /
requires human review.

## Category summary

- **A (segmentation-related)**: `A_value`, `D_px` — aggregate statistics look fine; risk is in specific
  edge cases (mask fragments, edge-adjacent lesions, false-positive-dominated contours) that only show
  up case-by-case.
- **B (feature-calculation problem)**: `B_circularity` — not a bug in the arithmetic itself, but a
  misleading variable name plus a multivariate sign-flip caused by multicollinearity with features the
  ablation study already knew were near-duplicates.
- **C (weak discrimination)**: `dark_fraction`, `eccentricity` most clearly; `bluegray_fraction`,
  `red_fraction`, `C_value`, `D_px` to a lesser degree.
- **D (insufficient evidence / requires human review)**: `lesion_fraction`, `D_px_normalized` (framing
  confound question), `skin_contrast` (reproducible but clinically counter-intuitive direction),
  `red_fraction` (sparse/skewed distribution).

No feature was found to be an outright implementation bug (wrong formula, off-by-one, incorrect masking).
The concerns found are, in order of how actionable they are: (1) `B_circularity`'s naming/sign-flip
(cheap to at least document, possibly cheap to fix by dropping the redundant `isoperimetric_ratio`-like
duplication driving it), (2) the `lesion_fraction`/`D_px_normalized` redundancy (already flagged by the
pipeline's own prior research as the single biggest concern in the 11 new features), (3) several
color-fraction features (`dark_fraction`, `bluegray_fraction`) that are close to non-informative as
currently thresholded, and (4) `eccentricity`, which shows no defensible standalone signal on either
cohort.
